# 微信小程序编译与真机验收

1. 用 HBuilderX 导入 `h5/呱呱去水印`。当前默认云托管 `container` 模式，核对 `config/features.js` 中业务环境、服务名、存储环境和桶，以及 `manifest.json` 的小程序 AppID。
2. 后端先按[部署说明](../../部署说明.md)完成数据库迁移、环境变量、私有入口限制与容器发布。
3. 在 HBuilderX 发行微信小程序，将 `unpackage/dist/build/mp-weixin` 导入微信开发者工具；源码目录不能直接当编译产物导入。
4. 重新编译、预览扫码，验证真实额度、图片和视频解析、云存储转存、隐私授权和相册保存。分享奖励用两个不同微信账号验证；完整观看与中途关闭广告分别验证。

本机 HTTP 模式只用于电脑模拟器，需显式切换配置并启动本机后端。手机上的 `127.0.0.1` 指向手机自身，真机使用云托管。

当前 Vue 2 编译器在部分环境从 `globalThis.wx` 读取 API。`build/wechat-native-wx-plugin.cjs` 会将已存在的原生 wx 同步到缺失的全局属性；没有原生 wx 时不会伪造对象。编译产物应包含 `guagua-native-wx-bootstrap-v1` 标记。

在小程序源码目录执行：

```bash
node tests/wx-runtime.cjs
node scripts/check-weixin.cjs unpackage/dist/build/mp-weixin
node tests/wx-built-runtime.cjs unpackage/dist/build/mp-weixin
```

后两项需要先生成微信生产包，检查包体、资源、按需加载、压缩及 wx 适配模块初始化。包体检查和模拟测试不能替代微信真机与云端权限验收。输出只显示在终端，无需保存本地日志。
