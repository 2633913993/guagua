# 媒体保存说明

当前保存链路：`callContainer` 提交 `/api/download/submit` → 轮询 `/api/download/status` → `wx.cloud.downloadFile` → 识别实际文件类型 → 保存相册 → 清理本次临时文件。不将解析接口返回的 JSON 当作视频，也不使用公网任意 URL 代理。

`services/cloud-download.js` 校验 fileID 的环境和存储桶，并处理转存、轮询和下载。`services/media-save.js` 根据最多 512 字节文件头及响应信息识别图片/视频，必要时复制为正确后缀再保存。错误网页、JSON 和空文件会被拒绝；改扩展名不能代替视频转码。

保存期间阻止重复点击，分别显示转存、下载和相册保存进度。失败时区分权限、隐私授权、格式、空间和网络问题。当前请求配置见[前端 README](README.md)。

微信后台需配置隐私声明，真机分别验证图片和视频、授权同意与拒绝、多图保存和临时文件清理。自动化相册 API 模拟测试不等于真实设备验收。云端配置见[转存部署说明](../../api/media_parser_fastapi/云存储转存部署说明.md)。
