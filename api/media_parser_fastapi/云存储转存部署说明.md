# 微信云托管内部临时凭证下载转存

本版替代手动 COS 永久密钥 / CloudBase API Key 的旧实现。业务服务继续仅通过微信私有入口调用，后台从固定的云托管内部接口取得临时凭证；没有新增公网下载接口。

## 已配置的存储

- 环境 ID：`prod-d3gk2acox7105dd30`
- Bucket：`7072-prod-d3gk2acox7105dd30-1385311964`
- Region：`ap-shanghai`
- 图片对象键：`img/{uuid}.{ext}`
- 视频对象键：`video/{uuid}.{ext}`
- 其他二进制文件：`downloads/{uuid}.{ext}`

对象键不重复包含 Bucket 名。以上为代码默认值，CLOUD_STORAGE_ENV、COS_BUCKET、COS_REGION 可覆盖。

## 五步执行流程

1. 后台任务通过 `GET http://api.weixin.qq.com/_/cos/getauth` 获取 TmpSecretId、TmpSecretKey、Token、ExpiredTime，初始化腾讯云 COS SDK。凭证仅保留在后端内存，快过期时刷新，不返回给小程序，不写入任务表。
2. 使用移动端 UA 和按平台匹配的 Referer 请求外链；逐跳校验重定向、固定已校验的公网 DNS 地址、禁止内网和元数据地址。超时时间为连接 10 秒、读取 60 秒，使用流式响应。
3. 用对象键构造 `cloud://{环境ID}.{Bucket}/{对象键}`。另外调用 `POST http://api.weixin.qq.com/_/cos/metaid/encode`，请求体包含可信微信身份 openid、bucket、paths，从 `respdata.x_cos_meta_field_strs[0]` 取得元数据。写入 `x-cos-meta-fileid` 的是该编码元数据，不能直接填 cloud:// 字符串。openid 来自私有网关可信身份，不接受前端自报。
4. 外链有 Content-Length 时，将仅可顺序读取的响应流包装为 COS SDK Body，调用 put_object；每次读取最多 64KiB，不预读完整文件，不计算需要重读整个流的 MD5，不自动重试不可回退的流。外链没有 Content-Length 时，按 4MiB 固定分块流式上传；失败终止未完成分块。所有写入均携带文件元数据。
5. 上传与完整性检查成功后，任务状态变为 success 并返回 fileID。小程序通过 wx.cloud.downloadFile 下载到临时路径，再保存相册，最后清理临时文件。

云托管内部 API 使用固定 HTTP 平台路由；禁用系统代理并禁止重定向。COS 文件传输使用 HTTPS 并保留证书校验。外部文件的 SSRF 限制不应用于固定的平台内部路由。

## 部署

1. 新库使用 `migrations/latest_schema.sql`；已有库按根目录部署说明补齐缺失的 001～005 迁移。下载功能需要 003，广告需要 004，累计解析数需要 005；执行历史统计回填时暂停解析流量。
2. 在后端目录执行 `python -m pip install -r requirements.txt`，或按已有 Dockerfile 重新构建服务。本次未再下载 SDK。
3. 继续保留 DATABASE_URL、WECHAT_ALLOWED_APPIDS、WECHAT_PRIVATE_INGRESS_ONLY 等现有业务配置；关闭全部业务公网入口后，WECHAT_PRIVATE_INGRESS_ONLY 必须为 true。
4. 重新部署后端服务。内部临时凭证方案不依赖 CLOUD_DOWNLOAD_ENABLED、CLOUDBASE_API_KEY、COS_SECRET_ID、COS_SECRET_KEY、COS_SESSION_TOKEN；即使云端保留旧的 CLOUD_DOWNLOAD_ENABLED=false，本版也不再读取它。
5. 确认服务运行在上述微信云托管环境内，并具备该环境对象存储的访问能力。普通本地运行不能调用云托管内部路由，不要为了本地调试而开放业务公网入口。
6. 重新编译前端并上传或预览。config/features.js 已配置 cloudEnv、cloudStorageEnv、cloudStorageBucket；前端只使用 callContainer 提交/查询以及微信云存储 SDK 下载，fileID 所属环境和桶必须匹配。

运行参数可选：

```dotenv

COS_BUCKET=7072-prod-d3gk2acox7105dd30-1385311964
COS_REGION=ap-shanghai
DOWNLOAD_MAX_BYTES=536870912
DOWNLOAD_DEADLINE_SECONDS=300
```

## 接口

`POST /api/download/submit` 接收 `{ "url": "外部文件地址" }`，立即返回 `{ "code": 0, "task_id": "任务号" }`。

`GET /api/download/status?task_id=任务号` 返回 processing、success + fileID，或 failed + msg。均通过私有网关身份鉴权，只允许查询自己的任务。

数据库仅保存任务状态与文件标识，不需要把 MySQL 与 COS 进行额外的关联操作。单个微信用户同时只允许一个任务，每个进程最多 4 个任务；状态查询有效期为 1 小时。

任务执行使用 FastAPI BackgroundTasks，实例重启不自动续传，15 分钟仍未结束的任务会提示失败。部署期间保留至少 1 个实例，避免任务运行时休眠或缩容；需要跨重启自动恢复时应另接持久化队列。

为 img/、video/ 和 downloads/ 配置所需对象生命周期，并配置未完成分块清理。数据库状态过期不会删除 COS 文件。可定期分批清理过期数据库记录：

```sql
DELETE FROM download_tasks WHERE expires_at < UTC_TIMESTAMP(6) LIMIT 1000;
```

测试命令见[后端 README](README.md)。存储回归包含模拟的内部临时凭证与元数据接口、实际 COS SDK 向回环测试服务的流式传输。真实 MySQL 验证需要另建可丢弃空测试库。

模拟测试不能替代线上权限验证。部署后需在实际微信云托管实例和真机验证 fileID 所属环境、文件可下载、相册保存及失败处理。
